# YouTube_Speed_Unblocker

Userscript для Tampermonkey/Violentmonkey: кнопки скорости поверх плеера YouTube — `−` / сброс / `+`. Работает в обычных видео и Shorts, скорость запоминается между роликами.

## Установка

1. Поставь расширение Tampermonkey или Violentmonkey.
2. Открой файл [`youtube-speed.user.js`](youtube-speed.user.js) → кнопка «Raw».
3. Расширение предложит установить скрипт — подтверди.

## Как пользоваться

- Наведи курсор на видео — появится панель.
- `−` / `+` меняют скорость на 0,25 (от 0,1x до 16x).
- Клик по значению (`1.5x`) сбрасывает скорость на 1x.
- Панель прячется синхронно с плашкой «Перевести видео» из скрипта VOT: через заданную задержку после последнего движения курсора над видео. Клик мимо видео прячет её сразу.

## Где панель

- Обычное видео — сверху, правее плашки «Перевести видео». Привязана к центру плеера, поэтому в полноэкранном режиме не уезжает.
- Shorts — снизу справа, на уровне строки с каналом.

Положение и время задержки меняются константами в начале скрипта: `VIDEO_TOP`, `VIDEO_SHIFT`, `SHORTS_BOTTOM`, `SHORTS_RIGHT`, `HIDE_DELAY_MS`.

`HIDE_DELAY_MS` должна совпадать с настройкой VOT «Delay before hiding the translate button» (по умолчанию 1000 мс).
